# House Price Prediction

## Overview

This project predicts house prices using Machine Learning techniques.

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-Learn
* Matplotlib
* Jupyter Notebook

## Files

* housing.csv : Dataset
* house_price_prediction.ipynb : Model training and prediction notebook

## How to Run

1. Install required libraries.
2. Open the notebook.
3. Run all cells.
